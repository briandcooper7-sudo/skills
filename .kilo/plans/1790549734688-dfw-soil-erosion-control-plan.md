# DFW Soil Erosion Control Plan

## Problem Summary
- **Type**: Erosion on slope, large area (over 200 sq ft), existing condition
- **Location**: Yard area
- **Soil Context**: DFW Texas - Black gumbo clay (expansive), alkaline pH (~8-9)

## Key Challenges

### DFW Soil Conditions
| Factor | Impact |
|--------|--------|
| **Expansive Clay** | Swells when wet, shrinks when dry → wall movement, cracking |
| **Poor Drainage** | Clay holds water → hydrostatic pressure against walls |
| **Freeze-Thaw Cycles** | Winter expansion → frost heave, joint movement |
| **Flash Flooding** | Severe storms dump 4-8" rain in 2 hours |
| **High pH** | Affects vegetation selection |

### Erosion Drivers
- Inadequate drainage concentrates water flow
- Clay erodes catastrophically when saturated
- Existing erosion indicates chronic drainage issue
- Slope angle > 3:1 (3:1 horizontal to 1 vertical) accelerates erosion

## Option A: Retaining Wall System (Recommended for Existing Erosion)

### Design Requirements for DFW Clay
- **Footing Depth**: Minimum 12" below grade, 8" wider than wall
- **Drainage**: Continuous perforated pipe (4" PVC) with gravel chamber
- **Base**: 6-8" compacted base course (3/4" minus aggregate)
- **Backfill**: 12" free drain zone behind wall
- **Reinforcement**: For walls > 3', consider geogrid intervals

### Wall Types (Ranked for Clay Soil)

| Type | Height Limit | Clay Suitability | Cost | Installation |
|------|--------------|------------------|------|--------------|
| **Segmental Concrete** | Unlimited | Excellent | $$ | Moderate |
| **Timber (Levee)** | 3-4' | Good (replace every 10-15 yr) | $ | Easy |
| **Stone/Masonry** | 4-6' | Good | $$$ | Difficult |
| **MSE (Muscular)** | Unlimited | Excellent | $$$ | Complex |

### Recommended: Segmental Concrete Block Wall
```
Design for 10' maximum height, 2:1 slope angle:
- 12" wide x 10" deep footing, compacted 3/4" base
- 4" drain pipe with 12" gravel chamber
- 6" coarse grout behind each course
- Top course raked 1/4" for drainage
- Capstone with weep hole at 2' intervals
```

## Option B: Terraced Earth Retention (Bioengineering)

### Hybrid Retaining-TERRAIN Approach
Best for large slopes where aesthetics matter:

1. **Create 3-4 foot step drops** (terracing)
2. **Root cellars** (3' deep behind each terrace)
3. **Native grasses**: Gulf Muhly, Buffalograss, Texas Bandgrass
4. **Shrubs**: American Beautyberry, Texas Sage, Chinkapin Oak

### Drainage Implementation
- Perforated pipe at each terrace bottom
- Gravel filter fabric (20-30 lb/yd²)
- 18" wide gravel shoulder on each side

## Option C: Drainage-First Approach (Temporary + Permanent)

### Immediate Stabilization (Week 1)
1. **Hydroseed with tackifier** (provides 6-8 weeks erosion protection)
2. **Install temporary straw wattles** at 3' intervals
3. **Diversion ditches** 10' upslope, redirect water away

### Permanent Solution (Week 3-4)
1. **French drain system** along eroded area
   - 8" perforated pipe in 6" gravel
   - Geotextile fabric wrap
   - 1' gravel cap visible above ground
2. **Soil amendment**: Mix in 20% coarse sand for drainage
3. **Native plant installation**: Select drought-tolerant species

## Detailed Retaining Wall Layout (Option A)

### Materials List (per linear foot)
| Item | Quantity |
|------|----------|
| Segmental block (8" thick) | 1 course per ft |
| Drain pipe (4") | 12" deep |
| Crushed stone (3/4") | 12" layer behind |
| Geo fabric | Full width behind |
| Compactable base | 6" layer |

### Construction Sequence
1. **Excavate** 8" below finished grade, 2" wider than block
2. **Install base** - 6" compacted 3/4" minus aggregate
3. **Set first course** - level, 1/4" bed mortar optional
4. **Add drain pipe** - slot front, cover with filter fabric
5. **Backfill** - 6" gravel, compact, add next course
6. **Install weep holes** - every 2 courses
7. **Cap** - final course with weep at 2' intervals

### DFW-Specific Considerations
- ** frost line**: 12-18" in DFW - footing below this depth
- ** Soil expansion**: Allow 2" gap between wall tops and any structures
- **Utility clearance**: Verify underground lines before excavation
- **Building permit**: Required for walls > 4' high in DFW metro areas

## Maintenance Requirements

### Annual Inspection Schedule
- **Spring**: Check drainage outlets, clear debris
- **After major storms**: Inspect for settling, movement
- **Fall**: Trim vegetation, check wall integrity
- **Winter**: Monitor for frost-related issues

### Expected Lifespan
- Segmental block: 50+ years with proper drainage
- Timber: 10-15 years (needs periodic replacement)
- MSE: 100+ years
